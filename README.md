## 🚀 Proyecto Destacado

### **Vercom ERP** — Sistema de Gestión Empresarial + App POS Android

Un ERP completo para una S.U.R.L. cubana que cubre contabilidad, inventario, producción, RR.HH. y punto de venta, cumpliendo normativas **NCC/NCIF, ONAT y Resolución 60/2011 de la CGR**.

**Características técnicas destacadas:**

- **Backend:** ASP.NET Core MVC (.NET 10) + EF Core + SQL Server.
- **Multi-Tenancy Row-Level** con Global Query Filters.
- **Auditoría inmutable** a dos niveles (SaveChangesInterceptor + triggers SQL).
- **Numeración consecutiva garantizada** (UPDLOCK, ROWLOCK).
- **App POS Android Nativa** (Kotlin + Jetpack Compose) con soporte **offline-first**.
- **Despliegue en Linux Debian** con Nginx + systemd.
