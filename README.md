## 🚀 Proyecto Destacado

### **Vercom ERP** — Sistema de Gestión Empresarial + App POS Android

ERP integral para una S.U.R.L. cubana con módulos de **contabilidad, inventario, producción, RR.HH. y punto de venta**, conforme a **NCC/NCIF, ONAT y Resolución 60/2011 de la CGR**.

**✨ Características técnicas destacadas:**

- 🏗️ **Backend:** ASP.NET Core MVC (.NET 10) + EF Core + SQL Server
- 🔐 **Multi-Tenancy Row-Level** con Global Query Filters
- 📝 **Auditoría inmutable** a dos niveles (SaveChangesInterceptor + triggers SQL)
- 🔢 **Numeración consecutiva garantizada** con UPDLOCK/ROWLOCK
- 📱 **App POS Android nativa** (Kotlin + Jetpack Compose) **offline-first**
- 🚀 **Despliegue en Linux Debian** con Nginx + systemd
